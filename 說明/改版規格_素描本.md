# 改版規格｜素描本風格（Sketchbook）

> **版本**：v1.0（2026-10-10）　**規劃 / 審查**：Claude Code　**執行**：Antigravity
> **範圍**：只改 `site/` 的外觀（HTML 結構、CSS、JS 裡的顯示文字）。**功能、API 呼叫、元素 id、狀態邏輯一律不動。**
> **參考稿**：`說明/design/sketchbook-reference.html`（用瀏覽器直接打開。學生頁手機版的目標長相）
> **靈感來源**：Google「限時塗鴉」（quickdraw.withgoogle.com）：白紙、黑色墨線手繪、只用一個亮黃色當重點色。

---

## 0. 為什麼改

現在的網站是「AI 預設風格」：深藍灰底、紫色漸層、每個標題都加 emoji、圓角卡片配陰影。
新方向是**一本學生的素描本**：米白紙張、黑色墨線、黃色螢光筆、手寫字。
要讓學生覺得「我在跟 AI 一起畫圖」，而不是「我在操作一個 AI 產品」。

**三個關鍵字：紙、墨線、黃色。** 不屬於這三樣的東西，都要有理由才能出現。

## 1. 設計 token（全部定義在 `style.css` 的 `:root`）

### 1-1 顏色

| token | 淺色（白天的素描本） | 深色（夜晚的炭筆本） | 用途 |
|---|---|---|---|
| `--paper` | `#FBF8F1` | `#1C1B18` | 頁面底色 |
| `--paper-2` | `#F3EEE2` | `#25231F` | 次要區塊（例如照片預覽框） |
| `--ink` | `#1F1F1F` | `#F1ECE0` | 主要文字、所有線條與邊框 |
| `--ink-2` | `#5E5A52` | `#B9B2A3` | 次要文字 |
| `--rule` | `#D9D2C3` | `#3A3731` | 橫格線、分隔線 |
| `--highlight` | `#FFD43B` | `#F2C230` | **唯一的重點色**：主要按鈕、選中狀態、開放中 |
| `--on-highlight` | `#1F1F1F` | `#1F1F1F` | 黃色上面的文字（深色模式也是黑字） |
| `--pencil-red` | `#C92A2A` | `#FF8787` | 錯誤、關閉中、被擋（像紅筆批改） |
| `--pencil-green` | `#2B8A3E` | `#69DB7C` | 成功（只用在老師頁的狀態與標籤） |
| `--tape` | `rgba(255, 212, 59, 0.55)` | `rgba(242, 194, 48, 0.45)` | 貼作品的紙膠帶 |

- 深色模式照舊用 `@media (prefers-color-scheme: dark)` 切換。
- **禁止**：漸層（`linear-gradient` 只准用來畫橫格線，見 3-3）、`box-shadow` 模糊陰影、`filter: blur`、紫色或藍色系主色。
- 對比：`--ink` 和 `--ink-2` 放在 `--paper` 上的對比度都要 ≥ 4.5:1（上表數值已符合，不要自己改淡）。

### 1-2 字體

```css
--font-hand: "Iansui", "BiauKai", "DFKai-SB", "Kaiti TC", "PingFang TC", "Microsoft JhengHei", serif;
--font-body: "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", system-ui, sans-serif;
```

- `--font-hand`（芫荽，手寫感）：站名、區塊標題、按鈕、通行碼數字、提示便條。
- `--font-body`：輸入框內容、說明小字、老師頁的表格內容（可讀性優先）。
- 從 Google Fonts 載入 `Iansui` 與 `Noto Sans TC`，要加 `&display=swap`。
- **學校網路常擋 Google Fonts**：字體載入失敗時，版面不能壞掉。備援字體是標楷體，看起來仍然像手寫。請在 Chrome DevTools 把 `fonts.googleapis.com` 封鎖後截一張圖，確認這一點。
- 字重只用 400。芫荽只有一種字重，不要用 `font-weight: bold` 硬加粗。

### 1-3 線條與形狀

| token | 值 | 用途 |
|---|---|---|
| `--line` | `1.5px solid var(--ink)` | 所有邊框 |
| `--line-dashed` | `1.5px dashed var(--ink)` | 未選中的選項、上傳區 |
| `--wobble-1` | `10px 14px 9px 12px` | 不規則圓角，模仿手畫的框 |
| `--wobble-2` | `12px 9px 14px 10px` | |
| `--wobble-3` | `9px 12px 10px 14px` | |
| `--pill` | `999px` | 主要按鈕、狀態標籤 |

- ⚠️ **深色模式的陷阱**：`--line: 1.5px solid var(--ink)` 裡的 `var(--ink)` 是在**定義 `--line` 的那個元素上**解析的。深色模式如果只覆寫 `--ink`，而 `--line` 沒有在同一個選擇器裡重新宣告，邊框會停留在淺色模式的黑色，在深色紙上就看不見了（我做參考稿時就踩到這個問題）。**在深色模式的區塊裡，要把 `--line`、`--line-dashed` 跟 `--ink` 一起重新宣告。**
- 卡片和選項輪流套用 `--wobble-1/2/3`，不要每個框都一樣圓。
- 少數元素可以有一點點傾斜（`transform: rotate(-0.6deg)` 到 `0.8deg` 之間），**每個畫面最多 3 個**：站名下的底線、提示便條、作品照片。按鈕和輸入框**不准**傾斜。

## 2. 全站規則

1. **畫面上不准出現 emoji**，包括 HTML 文字、JS 裡會顯示的字串（例如 `'🚀 開始畫圖'`、`'🟢 開放中'`、`'⏳ 請稍候'`）。
   - 需要圖示的地方，改用**內嵌 SVG 線稿**：`stroke="currentColor"`、`stroke-width="1.8"`、`fill="none"`、`stroke-linecap="round"`。
   - 後端回傳的風格 `label` 本身含有 emoji，這是 API 合約，不能改。前端顯示時一律去掉：`label.replace(/\p{Extended_Pictographic}️?/gu, '').trim()`。
   - 例外：`site/assets/api.js` 的 mock 資料要跟後端一模一樣，所以可以保留 emoji。
2. **不准用圖片檔**。所有塗鴉都用內嵌 SVG，好讓顏色跟著深淺模式切換。
3. **不准加任何 JS 套件或 CDN 腳本**。CSP 的 `script-src 'self'` 不變。
4. **CSP 要配合字體來源調整**（兩個 HTML 都要改）：`style-src` 加上 `https://fonts.googleapis.com`，並新增 `font-src https://fonts.gstatic.com`。其他指令不變。
5. 動畫一律包在 `@media (prefers-reduced-motion: no-preference)` 裡面。
6. 所有元素 `id`、`class` 裡被 JS 用到的名稱都不准改名。要新增 class 可以，要刪除前先用 `grep` 確認 JS 沒在用。
7. 觸控區 ≥ 48px、內文 ≥ 16px、360px 寬不准水平捲動。這些規則照舊。

## 3. 學生頁 `index.html`

由上到下：

### 3-1 測試模式提示
現在的橘色漸層橫幅，改成一張**黃色便利貼**：`--highlight` 底、`--line` 邊框，稍微傾斜 `-1deg`，固定在頁首右上角。
文字：「測試模式：畫出來的是假圖，不會用到額度」。

### 3-2 頁首
- 左邊：站名，用 `--font-hand`，約 26px（手機 22px）。下面一條**手畫的波浪底線**，用內嵌 SVG 的 `path` 畫，不要用 `border-bottom`。
- 站名旁邊放 1～2 個小塗鴉，例如鉛筆、星星，內嵌 SVG，`aria-hidden="true"`。**全頁塗鴉最多 3 個。**
- 右邊：狀態標籤，形狀用 `--pill`：
  - 開放中：`--highlight` 底，文字「開放中（到 14:50）」
  - 尚未開放：透明底、`--pencil-red` 邊框與文字，文字「還沒開放」
- 剩餘次數：一行小字「你今天還可以畫 8 張」，用 `--font-hand`、`--ink-2`。全班剩餘次數改成更小的字放在後面，或移到 `title`。

### 3-3 主要區塊
- **不要卡片陰影、不要深色卡片**。區塊之間用一條 `--rule` 分隔，或直接留白。
- **模式切換**（用文字畫圖／把照片變風格）：兩個並排的分頁。選中的那個用 `--highlight` 底配 `--line` 邊框，沒選中的用 `--line-dashed`。
- **風格選擇**：小標題「選一種畫風」（`--font-hand`）。7 個選項排成網格（手機 3 欄、桌機 4 欄）：
  - 選中：`--highlight` 底、`--line` 邊框
  - 未選中：透明底、`--line-dashed` 邊框
  - 每格只放文字（去掉 emoji 後的風格名稱）。如果要加圖示，每種風格各畫一個簡單的 SVG 線稿，7 個都要有，**不要有些有、有些沒有**
- **描述小幫手**：四個小欄位改成「填空句」的樣子，像在作業簿上填寫：
  `[主角是誰]` 在 `[哪裡]` `[做什麼]`，感覺 `[怎麼樣]`
  欄位只有底線（`border-bottom: var(--line)`），沒有外框。手機寬度不夠時可以換行。
- **「AI 會收到的描述」文字框**：底色是橫格紙，用 `repeating-linear-gradient` 畫 `--rule` 色的橫線，行高要對齊格線。這是全站唯一允許的 gradient。
- **給我靈感**：三個小按鈕，`--line-dashed` 邊框，`--font-hand`。

### 3-4 開始按鈕
- 全寬、`--pill`、`--highlight` 底、`--line` 邊框、`--font-hand` 約 20px，文字「開始畫！」。
- 冷卻中：文字「休息一下，還有 12 秒」，底色改成透明、邊框改成 `--line-dashed`。**不要只靠把按鈕變淡來表示**，國小學生看不懂。
- 生成中：文字「AI 正在畫…」。

### 3-5 生成中的動畫
- 取代現在的進度條：一支 SVG 鉛筆，在一條波浪線上來回塗鴉（用 `stroke-dashoffset` 做描線動畫）。下面輪播提示文字。
- `prefers-reduced-motion` 時不播動畫，只顯示靜態的鉛筆和文字。

### 3-6 結果
- 作品像是**用紙膠帶貼在素描本上**：圖片外框是 `--line`、白色內距 8px（深色模式用 `--paper-2`），上方左右兩角各貼一段斜放的紙膠帶（用 `::before`／`::after` 畫，`--tape` 色）。整張稍微傾斜 `0.8deg`。
- 圖片下方用 `--font-hand` 寫一行說明，像美術作品的標籤：「《一隻戴帽子的貓》・水彩風・AI 生成」。描述太長就截斷到 16 字加「…」。
- 按鈕：「下載這張」（主要，黃色）、「再畫一張」（次要，`--line-dashed`）。

### 3-7 這節課的作品
- 縮圖做成小拍立得：白邊、底部比較寬、`--line` 邊框，每張輪流傾斜 -2°、1°、-1°。
- 目前選中的那張，底下畫一條 `--highlight` 螢光筆線。

### 3-8 提示訊息（錯誤、提醒）
- 改成「老師在旁邊寫的批註」：左邊一條 3px 的 `--pencil-red` 直線，配 `--font-hand` 文字。提醒類（非錯誤）用 `--ink-2`。**不要用紅底或黃底的大色塊。**
- 文字照用後端的 `message`，不准改寫。

### 3-9 班級通行碼畫面
- 大字標題「輸入班級通行碼」。輸入框做成 4 個像格子紙的方格（實際上仍然是**一個** `input`，用 `letter-spacing` 配背景格線做出效果，**不要拆成 4 個 input**），數字用 `--font-hand` 約 36px。
- 「通行碼已更換」的提示，用 3-8 的紅筆批註樣式。

### 3-10 頁尾
一行 `--ink-2` 小字：「這個網站由老師提供 AI 額度，請好好使用。你輸入的描述老師看得到。」（去掉 emoji，其餘文字不變）

## 4. 老師頁 `admin.html`

同一本素描本，但這是**老師的備課本**：比學生頁安靜，塗鴉 0～1 個，資訊密度優先。

- **服務開關**：四個按鈕排一列。目前狀態的按鈕用 `--highlight` 底，「立即關閉」用 `--pencil-red` 邊框和文字。倒數文字用 `--font-hand`。
- **班級通行碼（投影用）**：數字用 `--font-hand`，約 96px（手機 64px），放在格子紙背景上，投影到教室後排也要看得清楚。
- **今日用量**：進度條改成一條手畫框（`--line`），裡面用 `--highlight` 填滿。成功、失敗、被擋三個數字，用 `--pencil-green`、`--ink-2`、`--pencil-red` 標示。
- **限額設定**：表單欄位只有底線，沒有外框（跟 3-3 的填空句一樣）。「儲存設定」用黃色主要按鈕。
- **紀錄表**：
  - 表頭用 `--font-hand`，下方一條 `--line`；每列之間用 `--rule` 細線，**不要斑馬紋、不要卡片**
  - 結果代碼改成小標籤：成功用 `--pencil-green` 邊框與文字，被擋與失敗用 `--pencil-red`
  - 「封鎖此裝置」用 `--pencil-red` 的文字按鈕；「已封鎖（解除）」用 `--line-dashed`
- **登入畫面**：一個置中的區塊，標題「老師的備課本」、一個密碼欄（只有底線）、一個黃色按鈕。
